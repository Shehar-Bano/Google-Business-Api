================================================================================
                    DOCUMENTATION OF RECENT TASKS & DEPLOYMENTS
================================================================================

This document details all implementations, schema changes, and system integrations
completed for the Google Business API application.

--------------------------------------------------------------------------------
1. SUPPORT & CONTENT - TERMS & CONDITIONS CRUD
--------------------------------------------------------------------------------
* **Database & Migration**: Created the `terms_conditions` table to store terms and 
  agreements separately with columns for ID, title, slug, content (longText), 
  status, and timestamps.
* **Model Class (`TermsCondition.php`)**: Built the Eloquent model with automatic 
  slug generation on save.
* **Controller (`TermsConditionController.php`)**: Developed complete CRUD actions 
  supporting dynamic table column sorting and searching.
* **Admin Views**: Designed clean index (list table), create, and edit views.
  - Integrated **CKEditor 4** via CDN on the create and edit forms for rich text editing.
  - Implemented real-time Title-to-Slug auto-generation Javascript events.
* **Sidebar Menu**: Integrated "Terms & Conditions" directly under the 
  "Support & Content" sub-menu in `verticalMenu.blade.php`.

--------------------------------------------------------------------------------
2. SUBSCRIPTION PLANS FEATURE: MOST POPULAR FLAG
--------------------------------------------------------------------------------
* **Database Schema Update**: Added `is_popular` (boolean, default: false) column 
  to the `subscription_plans` table.
* **Model Class (`SubscriptionPlan.php`)**: Appended `is_popular` to `$fillable` 
  and casts array.
* **Controller Updates**: Updated the store/update logic to parse check box states. 
  Added sorting support by popularity.
* **Admin Forms & Table Grid**:
  - Inserted **"Mark as Most Popular Plan"** Bootstrap switch inside create and edit views.
  - Displayed a highlighted **"Popular"** star badge on the plan table grid.

--------------------------------------------------------------------------------
3. GOOGLE PLACES DETAIL GET API
--------------------------------------------------------------------------------
* **Endpoint**: Registered public API endpoint `GET /api/v1/google/place-details?place_id=PLACE_ID`.
* **API Controller (`GooglePlaceController.php`)**: Reads the `PLACES` API key from 
  `.env` to call Google Places Details API and returns details including: 
  formatted address, phone, website, rating, reviews total, editorial summary, 
  opening hours, and photos.

--------------------------------------------------------------------------------
4. GOOGLE PLACES SYNC CRON JOB & ESTIMATED SCORE SYSTEM FIX
--------------------------------------------------------------------------------
* **Artisan Console Command (`UpdateBusinessFromPlaces.php`)**:
  - Automatically queries the Google Places Details API for registered businesses 
    using their `google_place_id`.
  - Syncs name, rating, reviews, formatted address, phone, and geometry location.
* **Address Components Schema Update**: Added missing `country`, `state`, `city`, 
  and `pincode` columns to the `businesses` table, and modified model `$fillable` 
  attributes to allow database writes.
* **Google Photos Sync**: Parses the Places `photos` response array, constructs 
  direct maps photo reference links, and syncs them to the `preferences_images` 
  table under type `google_places`.
* **Database String Truncate Fix**: Updated `preferences_images.image` column type 
  from `VARCHAR(255)` to `TEXT` type to prevent database truncation errors on 
  long Google Places photo reference keys.
* **Explicit Recalculation Trigger**: Added explicit score recalculation 
  `BusinessScoreCalculator::recalculate` at the end of the sync loop. This 
  ensures the points for country, state, city, pincode, and business photos (>= 10) 
  are awarded to the user instantly.
* **Task Scheduling**: Configured the Artisan command (`business:update-places`) 
  to run daily inside `routes/console.php`.
